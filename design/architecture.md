# 構成と仕組み

## ファイル構成（game/）

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（キャンバス・HUD・タイトル・ゲームオーバー）。スクリプトを順に読み込む |
| `css/style.css` | 見た目。スマホ縦画面を基本に、PC では横幅 480px で中央に置く |
| `js/config.js` | 調整用の設定値（大きさ・確率・点数・バージョン）。`window.OTTO_CONFIG` |
| `js/physics.js` | 箱だけを扱う 2D 物理エンジン。`window.Physics` |
| `js/chara.js` | キャラクターの描画（表情・焦り・光る演出）。`window.Chara` |
| `js/sound.js` | 効果音（Web Audio で合成）。`window.Sound` |
| `js/game.js` | ゲームの進行・入力・カメラ・描画。`window.OttoGame` |
| `js/ranking.js` | みんなのランキングの受け口とのやりとり。`window.Ranking` |
| `js/main.js` | 画面の切り替えとベストスコアの保存、ランキングの表示・名前の入力。ゲームとのつなぎ込み |
| `ranking.html` | ランキングだけのページ（ほかのページに iframe で貼る用） |
| `favicon.svg` | タブのアイコン |

- ES モジュールは使わず、普通の `<script>` で読み込む（`index.html` をファイルとして直接開いても動かすため）。
- 外部ライブラリ・CDN・Web フォントは使わない。

## 座標と単位

- ゲームの座標は「ワールド単位」。横幅を 360 とし、画面の横幅に合わせて拡大縮小する。縦は画面の縦横比で決まる。
- y 軸は下向き。土台の上面を y = 0 とする（上へ積むほど y はマイナス）。
- 物理エンジンにはメートルで渡す（60 ワールド単位 = 1m）。キャラクターは 約 1.03m × 1.13m の箱。

## 物理演算（physics.js）

Box2D-Lite と同じ考え方の、長方形どうしの剛体シミュレーション。

1. 2 つの箱の重なりを分離軸で調べ、接触点（最大 2 点）をクリッピングで求める。
2. 接触点ごとに、めり込みを戻す力と摩擦を「逐次インパルス法」で 12 回くり返して解く。
3. 前のフレームで使った力を引き継ぐ（ウォームスタート）ことで、積み上げても震えにくくする。
4. 1/60 秒の固定ステップで進める。

- 反発（はね返り）はない。「ぷにっ」とした柔らかさは、見た目だけのばね（下記）で表す。
- 新しくぶつかったときに `onImpact(bodyA, bodyB, 速さ)` を呼ぶ。

## キャラクターの描画（chara.js）

- 原画（assets_src/chara_original.jpg）の座標で線を引き、胴体の幅に合わせて縮小する。耳・腕・しっぽ・足は見た目だけで、当たり判定は胴体の四角のみ。
- 「ぷにっ」: 着地の速さに応じて、ばね（`squash`）に勢いを与える。描画時に足もとを支点として横に広げ・縦につぶす。
- 焦り（`panic` 0〜1）: 傾き・回転の速さ・滑り落ちる速さから求める。0.45 を超えると ◎ の目・震え・汗・腕のバタバタになる。上で待っているキャラも、タワーが危ないと焦る。
- 表情: `normal` / `kira` / `nemui` / `nikkori`。ときどきまばたきする。

## ゲームの流れ（game.js）

```
タイトル → あそぶ → [キャラが上に出る → タップで落とす → 着地・静止 → 判定] のくり返し → 3 匹落としたらゲームオーバー
```

- 次のキャラは、前に落としたキャラが静止したとき・落ちたとき・2.6 秒経ったときのいずれか（かつ最短 0.6 秒後）に出る。
- 静止の判定: 速さ・回転が小さい状態が 0.35 秒続いたら静止とみなし、その 1 回だけボーナスを判定する。
- 支えの相手: 真下（縦に半身〜1.4 匹分、横にキャラ幅以内）にいるいちばん近いキャラ。いなければ土台。
- タワーの高さ: 着地済みで速く動いていないキャラの上端のうち、いちばん高いもの。スコアは最高到達点で計算する（崩れても減らない）。
- 落下: 土台の上面から 260 下まで落ちた、または画面の左右へ大きく外れたら「落とした」として数える。
- カメラ: タワーの上端から一定の距離の上に出現位置を置き、それが画面の上のほうに来るよう、なめらかに追う。タワーが低いうちは土台が画面の下に見える位置で止める。

## 保存するデータ（localStorage）

| キー | 内容 |
|---|---|
| `ottotto.best` | ベストスコア（数値） |
| `ottotto.mute` | 効果音のオフ（`'1'` / `'0'`） |
| `ottotto.name` | ランキングに出す名前 |
| `ottotto.player` | 端末ごとのプレイヤー ID（英小文字と数字 20 文字、ランダム） |
| `ottotto.sentBest` | ランキングに送った最高点。これを超えたときだけ送る |

## みんなのランキング（ranking.js・gas/ranking.gs）

```
ゲーム ──POST（スコア）──▶ Google Apps Script のウェブアプリ ──▶ スプレッドシートに 1 行追加
ゲーム・ranking.html・ほかのページ ◀──GET（JSON）── 同じウェブアプリ
```

- 受け口の URL は `config.js` の `RANKING_URL`。空ならランキングの表示を隠す。準備の手順は [gas/README.md](../gas/README.md)。
- 送るときは `Content-Type: text/plain` で JSON を送る（ブラウザの事前確認（preflight）を避けるため。Apps Script は事前確認に応えられない）。
- 送る内容: `{action:'submit', playerId, name, score, heightCm, count}`。名前だけ変えるときは `{action:'rename', playerId, name}`。
- 取得: `GET ?n=件数&me=プレイヤーID` → `{ok, total, ranking:[{rank, name, score, heightCm, date, me}], mine}`。
  - プレイヤー ID は返さない（他人の ID で名前を書きかえられないように）。自分の行にだけ `me: true` を付ける。
- スプレッドシート
  - `scores`: 日時・プレイヤーID・スコア・高さ(cm)・匹数（送られるたびに 1 行）
  - `players`: プレイヤーID・名前（名前はここで一元管理し、変えたら過去の記録にも反映される）
- 集計: `scores` をプレイヤーごとに最高点でまとめ、点の高い順（同点は先に出した人が上）に並べる。`players` にいない ID は出さない。
- 同時に送られても行が壊れないよう、書き込みは `LockService` で 1 つずつ行う。
- はじく条件（匹数 = 落としたキャラの総数 n）: 高さ > 12n cm、または 点 > 120n + 25n(n+1) + 180n（高さ・ピタッと賞の連続・ギリギリ賞とレアをすべて満点で取ったときの上限）。
- 名前は制御文字を除いて 10 文字に切る。`=` `+` `-` `@` で始まる名前は、シートで数式にならないよう先頭に `'` を付けて保存する。表示はすべて `textContent` で入れる。

# 企画・ゲーム仕様：『もちもち四角バランス：おっとっとタワー』

## 1. 概要

| 項目 | 内容 |
|---|---|
| タイトル | もちもち四角バランス：おっとっとタワー |
| ジャンル | 物理演算バランスアクション / ミニゲーム |
| プラットフォーム | Web ブラウザ（スマホ・PC 両対応 / 完全無料公開） |
| ターゲット | 手軽にクスッと笑えるカジュアルゲームを楽しみたい人、短時間でリトライしたくなるゲームが好きな人 |

## 2. 世界観・キャラクター

- 主人公: 耳がピンと立ち、目が「(◎_◎)」のように特徴的な、ちょっぴりシュールで愛嬌のある四角い生き物（原画: [assets_src/chara_original.jpg](../assets_src/chara_original.jpg)）。
- カチコチの四角ではなく、着地した瞬間に「ぷにっ」と潰れて形が戻る、もちもちした動きをする。

## 3. ルール

### 3.1 基本ルール

1. 画面の上にキャラクターが現れる。プレイヤーはタップ（クリック）した位置に落とす。指でなぞって位置を決め、はなすと落ちる。
2. 土台の上にキャラクターを着地させ、崩れないように高く積み上げる。
3. キャラクターを **3 匹** ステージの外へ落としたらゲームオーバー。

### 3.2 スコア

| 要素 | 内容 | 点 |
|---|---|---|
| 高さ | タワーの最高到達点。キャラ 1 匹分 = 12cm | 1cm につき 10 点 |
| ピタッと賞 | 下のキャラとほぼ横ずれなく、まっすぐ重なった | 50 点 × 連続回数 |
| ギリギリ賞 | 大きくずれた・傾いた状態で着地し、2 秒耐えた | 80 点 |
| レア個体 | レア個体を無事に着地させた | 100 点 |

- ベストスコアは端末（ブラウザ）に保存する。

### 3.3 ランダム要素

- 傾いた状態で出てくることがある。積んだ数が増えるほど出やすくなる（最大 35%）。
- 低い確率（8%）で表情・色の違うレア個体が混ざる。
  - キラキラ（星の目・金色）、ねむい（閉じた目・Zzz）、にっこり（^ ^ の目）

## 4. 画面と演出

- 背景: 方眼紙風。左端に高さのものさし、最高到達点に点線を引く。
- キャラクターは手描きの線画をもとにした線で描く。
- うまく積めたとき（ピタッと賞など）は、キャラクターが「ピカッ」と光り、輪と火花が広がる。
- 危ないバランスのときは、キャラクターの目が見開いた「◎」になり、震えて汗をかき、腕をバタバタさせる。
- タワーが伸びると、画面が上へスクロールする。
- 効果音（落とす・ぷにっ・ピタッ・おっとっと）。右上のボタンでオン・オフできる。
- ゲームオーバー画面から結果を共有できる。
  - 「𝕏 にポスト」: X の投稿画面を新しいタブ（スマホは X のアプリ）で開く。本文（点数・高さ）・ゲームの URL・ハッシュタグ「#おっとっとタワー」を入れておき、投稿前に編集できる。
  - 「結果をシェア」: スマホは共有メニュー、PC はクリップボードにコピー。

## 5. 公開方針

- コードは HTML / CSS / JavaScript のみ。外部ライブラリ・サーバーを使わない。
- GitHub Pages で無料公開し、URL を家族や友人に送ってスマホからすぐ遊べるようにする。

# みんなのランキング（Google スプレッドシート）の準備

ランキングは Google スプレッドシートに記録します。受け口は Google Apps Script（[ranking.gs](ranking.gs)）です。どちらも Google アカウントがあれば無料で使えます。

## 1. スプレッドシートとスクリプトを作る

1. Google ドライブで新しいスプレッドシートを作る（名前は「おっとっとタワー ランキング」など、何でもよい）。
2. 作ったスプレッドシートを開き（ドライブの一覧ではダブルクリック）、画面上のメニュー（ファイル・編集・表示 … 拡張機能・ヘルプ）の **拡張機能 → Apps Script** を開く。
3. 最初からある `コード.gs` の中身をすべて消し、[ranking.gs](ranking.gs) の中身を貼り付けて保存する（💾 ボタン）。

シート（`scores` と `players`）は、最初にスコアが届いたときに自動で作られます。

## 2. ウェブアプリとしてデプロイする

1. Apps Script の画面右上の **デプロイ → 新しいデプロイ** を押す。
2. 「種類の選択」の ⚙ から **ウェブアプリ** を選ぶ。
3. 次のように設定して **デプロイ** を押す。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 初回は「アクセスを承認」を求められる。自分のアカウントを選び、「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** で許可する（自分で作ったスクリプトなので問題ありません）。
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピーする。

## 3. ゲームに URL を設定する

`game/js/config.js` の `RANKING_URL` に、コピーした URL を入れる。

```js
RANKING_URL: 'https://script.google.com/macros/s/……/exec',
```

空のままだと、ランキングの機能は表示されません（ゲームはそのまま遊べます）。

## スクリプトを直したとき

**デプロイ → デプロイを管理** で、いまのデプロイの ✏ を押し、バージョンを「新バージョン」にしてデプロイする。こうすると URL は変わりません（「新しいデプロイ」にすると URL が変わります）。

## 記録の管理

| シート | 列 | 内容 |
|---|---|---|
| `scores` | 日時・プレイヤーID・スコア・高さ(cm)・匹数 | スコアの登録 1 回につき 1 行 |
| `players` | プレイヤーID・名前 | 端末ごとのプレイヤーと、ランキングに出す名前 |

- ランキングは 1 人（1 端末）1 件で、その人のいちばん高いスコアを出します。
- おかしな記録は `scores` の行を消せば消えます。
- 名前を直したいときは `players` の名前を書きかえます。`players` から行を消すと、その人はランキングに出なくなります（その端末から次に自己ベストが送られると、また出ます）。

## ほかのページで表示する

- いちばん簡単なのは、ゲームと一緒に公開している `ranking.html` を iframe で貼ることです。

  ```html
  <iframe src="https://（ゲームの URL）/ranking.html" width="360" height="520" style="border:0"></iframe>
  ```

- 自分でデザインしたいときは、ウェブアプリの URL に `?n=件数` を付けて読み込むと、次のような JSON が返ります。

  ```json
  { "ok": true, "total": 12, "ranking": [ { "rank": 1, "name": "なまえ", "score": 1230, "heightCm": 84.0, "date": "2026-11-15", "me": false } ], "mine": null }
  ```

  ```html
  <ol id="otto-ranking"></ol>
  <script>
    fetch('https://script.google.com/macros/s/……/exec?n=10')
      .then((r) => r.json())
      .then((d) => {
        const ol = document.getElementById('otto-ranking');
        d.ranking.forEach((r) => {
          const li = document.createElement('li');
          li.textContent = `${r.name}　${r.score} てん`;
          ol.appendChild(li);
        });
      });
  </script>
  ```

- スプレッドシートの **ファイル → 共有 → ウェブに公開** で、シートを表としてそのまま貼ることもできます（この場合はプレイヤー ID も見えるので、おすすめしません）。

## 注意

- ブラウザで動くゲームなので、詳しい人ならスコアを偽って送ることができます。ありえない点数ははじきますが、仲間内で楽しむ前提の仕組みです。
- 名前とスコアは URL を知っている人なら誰でも見られます。本名ではなくニックネームを使ってください。

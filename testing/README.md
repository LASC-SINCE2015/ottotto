# テスト・確認 (testing)

おっとっとタワーで「何を確認するか」と「確認した結果」を残すフォルダです。

## 確認の種類

| 種類 | 対象 | 実行方法 |
|---|---|---|
| 動作確認 | PC のブラウザ | `game/index.html` をブラウザで直接開き、下のチェックリストを確認する |
| 実機確認 | スマホのブラウザ・公開サイト | GitHub Pages の URL を開いて確認する |

## チェックリスト

- [ ] タイトルでキャラクターが跳ねている。ベストスコアとバージョンが出る
- [ ] 「あそぶ」でゲームが始まり、上にキャラクターが出る
- [ ] タップ（クリック）した位置に落ちる。指でなぞると位置が動き、はなすと落ちる
- [ ] 着地で「ぷにっ」と潰れて戻る
- [ ] まっすぐ重ねると「ピタッ！」が出て光る。連続すると ×2, ×3 と増える
- [ ] 大きくずらして耐えると「ギリギリ賞！」が出る
- [ ] 傾いたキャラ・レア個体がときどき出る
- [ ] 危ないとき、目が ◎ になって震える
- [ ] 落とすと「おっとっと！」が出て、右上のライフが減る。3 匹でゲームオーバー
- [ ] 高く積むと画面が上へスクロールし、ものさしの目盛りが増える
- [ ] ゲームオーバー画面の「もういちど」「結果をシェア」「タイトルへ」が動く
- [ ] ベストスコアが再読み込みしても残る
- [ ] 右上の ♪ で効果音がオン・オフできる

## 結果の残し方

- 確認したら `results/<日付>_<ブランチ名>.md` を作る。
- 「対象（ブランチ・コミット）」「環境（ブラウザ・端末）」「結果」「見つかった問題」を書く。
